# Mappedin React Native Samples

This repo contains sample applications demonstrating different ways to integrate with the Mappedin SDK for React Native to render maps and build a custom indoor mapping experience. To learn more about ways to integrate with Mappedin, refer to [developer.mappedin.com](https://developer.mappedin.com/).

The Mappedin SDK for React Native enables you to build powerful and highly flexible indoor mapping experiences natively on Android and iOS.

---

## Mappedin SDK for React Native v6 Samples

To read more about the Mappedin SDK for React Native, refer to [Getting Started with Mappedin SDK for React Native](https://developer.mappedin.com/react-native-sdk/getting-started) and the additional guides in the Mappedin developer docs.

The sample projects in this repo provide a key and secret to access demo maps. Production apps will need their own key and secret. Refer to [Create a Key & Secret](https://developer.mappedin.com/react-native-sdk/getting-started#create-a-key--secret) for instructions on how to create your own.

The following table lists the sample projects that pertain to the latest version of the Mappedin SDK for React Native.

| **Sample** | **Description** | **Guide** |
| --- | --- | --- |
| [PlaygroundSamples](https://github.com/MappedIn/react-native/tree/master/SDKv6_Examples/PlaygroundSamples#readme) | A collection of samples demonstrating the core features of the Mappedin SDK for React Native, including labels, markers, wayfinding, Blue Dot, and more. | [Getting Started](https://developer.mappedin.com/react-native-sdk/getting-started) |
| [ReusableMapView](https://github.com/MappedIn/react-native/tree/master/SDKv6_Examples/ReusableMapView#readme) | Demonstrates reusing a single MapView across screens so the map loads once and reparents instantly between pages, avoiding repeated load times. | [Optimizing User Interface Performance](https://developer.mappedin.com/react-native-sdk/getting-started#optimizing-user-interface-performance) |
